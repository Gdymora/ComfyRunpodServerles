# Як працює інструмент маскування зображень в ComfyUI: технічне пояснення

Ви успішно реалізували функціонал маскування зображень для вашого застосунку, інтегрованого з **ComfyUI**. Давайте детально розберемо, як працює цей механізм і чому початково виникла проблема.

## Концепція масок у графічних редакторах

**Маска** — це чорно-біле або прозоре зображення, яке визначає, які частини основного зображення будуть видимі, а які — ні. У більшості графічних редакторів (Photoshop, GIMP) маски працюють за принципом:

- **Білі/непрозорі області маски**: показують відповідні частини зображення
- **Чорні/прозорі області маски**: приховують відповідні частини зображення

## Технічна реалізація масок в ComfyUI

**ComfyUI** використовує специфічний формат маски, де інформація зберігається в **альфа-каналі** PNG зображення:

- **RGB канали**: завжди чорні `(0,0,0)` для всього зображення
- **Альфа-канал**: визначає прозорість кожного пікселя

| Значення | Опис                |
| -------- | ------------------- |
| `0`      | Повністю прозорий   |
| `255`    | Повністю непрозорий |

## Чому виникла проблема?

Приклад коли інвертована логіка альфа-каналу:

```typescript
// Старий код з неправильною логікою
finalData.data[targetIdx + 3] = hasColor ? 255 : 0;  // A
```

Це призведе до того, що намальовані області, стануть **непрозорими (255)**, а решта зображення — **прозорою (0)**. В результаті ми побачимо тільки намальовані області, а решта зображення зникне.

## Інше рішення

Рішення інвертуваннія логіки альфа-каналу:

```typescript
// інвертована логіка
finalData.data[targetIdx + 3] = hasColor ? 0 : 255;  // A - інвертований!
```

Тепер області, які ми малюємо пензлем, стають **прозорими (0)**, а решта зображення залишається **непрозорою (255)**.

## Технічний процес обробки маски

### 1. Створення пікселів маски

```typescript
// RGB завжди чорний
finalData.data[targetIdx] = 0;       // R = 0
finalData.data[targetIdx + 1] = 0;   // G = 0
finalData.data[targetIdx + 2] = 0;   // B = 0

// Альфа-канал визначає прозорість
finalData.data[targetIdx + 3] = hasColor ? 0 : 255;  // A - інвертований
```
`targetIdx + 3` стосується індексації даних у масиві пікселів зображення.

У JavaScript, коли ми працюємо з даними зображення через API `getImageData()` та `putImageData()`, ми отримуємо та маніпулюємо з одновимірним масивом байтів, де для кожного пікселя зберігається 4 послідовні значення:

- `targetIdx` - індекс першого байта пікселя (червоний канал, R)
- `targetIdx + 1` - індекс другого байта пікселя (зелений канал, G)
- `targetIdx + 2` - індекс третього байта пікселя (синій канал, B)
- `targetIdx + 3` - індекс четвертого байта пікселя (альфа-канал, A)

Таким чином, коли ми пишемо:
```javascript
finalData.data[targetIdx + 3] = hasColor ? 0 : 255;
```

Ми модифікуємо саме альфа-канал поточного пікселя, який контролює його прозорість:
- Значення 0 означає повністю прозорий піксель
- Значення 255 означає повністю непрозорий піксель

Ця формула дозволяє нам точно вказати, які частини зображення повинні стати прозорими (ті, що ми розмалювали), а які - залишитися видимими.
### 2. Відправка на сервер

```typescript
// Створюємо формат запиту для ComfyUI
formData.append('image', blob, filename);
formData.append('original_ref', JSON.stringify({
  filename: originalRef.filename,
  type: originalRef.type
}));
formData.append('type', 'input');
formData.append('subfolder', 'clipspace');
```

### 3. Обробка на сервері

Сервер **ComfyUI** накладає маску на оригінальне зображення, зберігаючи тільки ті області, де альфа-канал маски має значення `255` (**непрозорий**), і робить прозорими ті області, де альфа-канал маски має значення `0` (**прозорий**).

## Як працюють основні компоненти маскування

### Canvas редактора

- Дозволяє користувачеві малювати в реальному часі
- Відстежує рухи миші та конвертує їх у пікселі маски

### Створення маски

- Маска генерується як PNG з **альфа-каналом**
- Розміри маски узгоджуються з розмірами оригінального зображення

### Завантаження на сервер

- Маска упаковується у **FormData** з правильними параметрами
- Сервер обробляє маску та застосовує її до зображення

## Поширені помилки при роботі з масками

### 1. Помилка "images do not match"

- **Причина**: Розміри маски не збігаються з розмірами оригінального зображення
- **Рішення**: Масштабування маски до оригінальних розмірів

### 2. Інвертована логіка маски

- **Причина**: Маска показує неправильні області
- **Рішення**: Інвертування значень **альфа-каналу**

### 3. Проблеми з форматом запиту

- **Причина**: Неправильні параметри в **FormData**
- **Рішення**: Копіювання точного формату запиту з оригінальних файлів **ComfyUI**

## Висновок

Технологія маскування в **ComfyUI** спирається на використання **альфа-каналу** PNG зображень, де чорне зображення з різними значеннями прозорості визначає, які частини оригінального зображення будуть видимі.

Ключовим аспектом є правильне налаштування **альфа-каналу**:

- Області, намальовані користувачем, повинні мати значення `0` (**прозорий**)
- Решта зображення — `255` (**непрозорий**)

Ваша реалізація тепер правильно слідує цьому принципу і успішно інтегрується з **ComfyUI** для створення та застосування масок до зображень.
