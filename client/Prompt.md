JSON з prompt для ComfyUI. Давайте розглянемо, які параметри є дійсно необхідними для відправки на /api/prompt.
Аналіз JSON структури
Наданий JSON містить:

client_id - ідентифікатор клієнта
prompt - основна структура з нодами воркфлоу
extra_data - додаткові дані, в тому числі опис всього воркфлоу

Необхідні параметри
Для базового функціонування /api/prompt достатньо:

client_id - для ідентифікації сесії
prompt - безпосередньо опис нод та їхніх з'єднань

extra_data є необов'язковим і служить здебільшого для відображення графу у веб-інтерфейсі. Ця частина може бути опущена при програмній взаємодії з API.
