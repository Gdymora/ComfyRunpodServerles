# Що ми передаємо на бекенд після малювання маски

Коли ми намалювали маску і натискаємо кнопку "Сохранить", наш редактор формує спеціальний запит до бекенду ComfyUI. Розглянемо детально, які дані передаються:
в кастомной ноде - impact-sam-editor.js
## 1. Дані для формування запиту

Метод `handleSave` в `MaskEditor.tsx` готує два основні елементи:

```typescript
onSave({
  maskBlob: blob,
  originalRef: initialImage
});
```

Потім в методі `uploadMask` в `api.ts` ці дані використовуються для створення FormData:

```typescript
const formData = new FormData();
formData.append('image', maskBlob, filename);
formData.append('original_ref', JSON.stringify({
  filename: originalRef.filename,
  type: originalRef.type
}));
formData.append('type', 'input');
formData.append('subfolder', 'clipspace');
```

## 2. Технічний зміст запиту

1. **image** - бінарні дані (Blob) зображення маски в форматі PNG. Це чорне зображення з альфа-каналом, де:
   - Пікселі, які ми намалювали пензлем, мають значення RGB(0,0,0) з Alpha=0 (прозорі)
   - Решта пікселів мають значення RGB(0,0,0) з Alpha=255 (непрозорі)

2. **original_ref** - JSON-рядок з інформацією про оригінальне зображення:
   ```json
   {
     "filename": "назва_файлу.png",
     "type": "input"
   }
   ```

3. **type** - завжди "input", вказує тип файлу для ComfyUI

4. **subfolder** - завжди "clipspace", вказує де зберігати маску

## 3. URL та метод запиту

Запит відправляється методом POST на URL:
```
${config.UPLOAD_URL}/mask
```

Наприклад: `http://127.0.0.1:8188/upload/mask`

## 4. Що відбувається на бекенді

Коли ComfyUI отримує такий запит:

1. Він зберігає маску у вказаній папці (clipspace)
2. Знаходить оригінальне зображення за допомогою `original_ref`
3. Застосовує маску до оригінального зображення, використовуючи альфа-канал
4. В результаті генерує нове зображення, де видно тільки ті частини оригінального зображення, які не були замасковані (не були розмальовані пензлем)

## 5. Особливості формату маски

Ключовий момент - інвертована логіка маски:
```typescript
finalData.data[targetIdx + 3] = hasColor ? 0 : 255;  // Alpha канал
```

Там, де ми малювали (hasColor = true), альфа-канал стає 0 (повністю прозорий). Це означає, що наші розмальовані області створюють "дірки" в масці, через які не видно оригінальне зображення.

## 6. Приклад

- Якщо ми малюємо круг на обличчі людини і зберігаємо маску
- Бекенд отримує PNG з прозорим кругом і непрозорою рештою
- В результаті обличчя зникає (стає прозорим), а все інше на фото залишається видимим

Цей механізм дозволяє нам точно вирізати певні частини зображення для подальшої обробки в системах ШІ, як ComfyUI.
